## 1. 市場・時間・価格単位

- 1 pip = 0.01円。価格計算は円単位、比較前にpipsを円へ変換する。
- 15分足の確定値のみで判定する。日時は足の終値時刻、JST（UTC+09:00）で保存する。
- 検証対象は08:00以上〜翌01:00未満。01:00〜08:00の新規セットアップ・エントリーはNO TRADE。01:00で未エントリー構造を終了し、翌セッションへ持ち越さない。
- 既存ポジションのTP・SL・16本タイムストップは時間外でも追跡する。参照用の過去32本は時間外の足も含む。

## 2. 重要高値・抵抗帯と試行

確定済みスイング高値は、対象足の高値が前2本・後2本の各高値より厳密に高いもの。同値は該当しない。後2本の確定前には利用しない。

新しい構造を選ぶ時点の直近32本の確定足内に対象足があるスイング高値を使う。抵抗帯は中心＝その高値、上端＝中心＋5pips、下端＝中心−5pips。複数候補は最も新しいスイング高値を選び、構造中に差し替えない。選定後に32本から外れてもその構造の帯は固定する。

抵抗帯と足の高安レンジが重なること（high >= 下端かつlow <= 上端）を進入とする。スイング高値そのものや、確定を待っている過去の足を試行へ遡及算入しない。選定の次の足から試行を数える。

最初の進入足を第1試行とする。次の試行には、前の接触群との間に抵抗帯へ接触しない確定足が最低3本必要。連続接触、または間隔不足の接触は同じ試行群として扱う。接触するたびに間隔の起点を更新する。最低2回の試行が必要。

2回目以降の試行足の終値が「抵抗帯上端＋3pips」より上でなければブレイク失敗候補。構造選定からエントリーまでのいずれかの足で、この水準を厳密に超えて終値確定したら無効。同値は無効としない。

## 3. 支持ラインと下抜け

支持ラインは第1試行足から最後の試行足まで（両端含む）のヒゲ最安値。接触群の最終接触足までを試行区間とする。

逐次判定では新しい抵抗帯接触がある間だけ区間を延長して最安値を更新する。抵抗帯への接触がない足で、2回以上の試行を終えた後、終値 <= 支持ライン−2pipsとなった最初の足を支持帯ブレイク足とする。最後の試行足とブレイク足は別の足でなければならない。

ブレイク成立時点の支持ラインを永久に固定する。後から別の安値・支持線へ変更しない。ヒゲだけの下抜けは不成立。

## 4. 戻り・戻り失敗・エントリー

- ブレイク足の次を1本目として、1〜6本目の足で支持ライン±5pipsのゾーンと高安レンジが重なることを戻りとする。ブレイク足内の戻りを推定しない。6本以内に戻らなければNO TRADE。
- ブレイク後からエントリーまで、終値が支持ライン＋3pipsを厳密に超えたら無効。同値は無効としない。
- 最初の戻り足以後で、陰線（close < open）かつ終値 < 支持ラインを満たす最初の足の終値を仮想ショート価格とする。戻り足自身も条件を満たせば可。
- 6本制限は最初の戻りまでに適用する。戻り後は最初のトリガー、無効化、または対象時間終了まで待つ。任意の足を選び直さない。
- 同じ足で無効条件とエントリー条件が競合したら無効を優先する。

## 5. SL・TP・タイムストップ

戻り局面の最高値は、最初の戻り足からトリガー足まで（両端含む）の最高値。SL＝その高値＋3pips。

D＝SL−entry、stop_pips＝D / 0.01。8pips未満または30pips超はNO TRADE。8、30pipsちょうどは含む。TP＝entry−1.5×D。部分利確・裁量利確・損切り拡大・建値移動は禁止。

エントリーは終値なので、TP・SL判定は次の足から行う。16本以内に到達した最初のTPまたはSLで決済し、どちらも到達しなければ16本目の終値で決済する。16本目でもTP・SLをタイムストップより優先する。

足内順序が15分足から判定できず同じ足で両方へ到達した場合はSL先行とする。下位足を都合よく追加して結果を変更しない。窓開けで始値がSLを超えた場合は始値で損切り、TPを下回った場合はTP価格で利確する。この足内・ギャップ規約を過去・フォワードとも同じ仮想評価に適用する。

## 6. 指標・その他のNO TRADE

米CPI、米PPI、米雇用統計、FOMC政策金利発表、FOMC議長会見、日銀政策決定、日銀総裁会見について、発表10分前以上〜15分後以下は新規エントリー禁止。15分後を過ぎて最初のトリガーが成立する場合は含める。禁止区間内のトリガーを後の足へずらして採用しない。ポジション保有中は出口を変更しない。

検証前にイベントカレンダーの時刻・情報源を保存する。時刻不明の対象イベントがある日は新規エントリーを保留してNO TRADE（event_time_unknown）。フォワードでは当時利用可能な予定時刻を保存し、実際の発表時刻が確認できたら併記する。後日判明した差分は削除せず逸脱記録に残す。

次をすべて記録する：

- スプレッド3pips超（3ちょうどは可）。エントリー時の値が不明ならデータ不足として保留。
- 検証対象時間外。
- 損切り幅8pips未満／30pips超。
- 抵抗帯または支持帯の定義が曖昧、必要足が欠損。
- ブレイク直後で戻りが存在しない、6本以内の戻りなし。
- 支持ライン回復（終値 > 支持ライン＋3pips）。
- 抵抗帯明確上抜け（終値 > 抵抗帯上端＋3pips）。
- 指標禁止区間、必要なイベント情報の欠損。

## 7. 同一構造の重複禁止

structure_idは抵抗帯の元スイング足の日時を基準とし、支持ラインを併記する。同じスイングを再利用して支持ラインだけ変更しても新構造にはしない。

1構造につき最大1つのトリガーを採点する。最初のトリガーがNO TRADEでも、その構造の後続シグナルを再採点しない。新サンプルには、それまで使用したものより後の確定済みスイング高値から新しく選定した抵抗帯が必要。同時に複数の帯を走らせない。終了後の次の足から新構造を選ぶ。異なる構造の仮想ポジションの重なりは記録して許容する。

## 8. 検証方式・データ・コスト

最低50件＝過去チャート30件＋条件固定後のフォワード観測20件。各群で時系列順の最初の有効完了件数を初回判定母集団とする。除外・未完了・データ不足は50件に数えず、行は保持する。本人が売買しなくても仮想条件を満たせば含め、本人の条件不一致トレードは混ぜない。

過去検証は2026-01-01T08:00:00+09:00から固定日時より前までを古い順に走査する（32本とスイング確認用の先行データを用意）。30件に満たなければデータ不足を報告し、期間を後付けで広げない。フォワードは固定日時以後に新規選定された構造を、観測開始から連続して記録する。観測開始を遅らせた場合は実際の開始日時を記録し、それ以前をフォワードとして後付けしない。

データの受入仕様：同一提供元のUSDJPY 15分OHLC、JSTへ変換可能な足時刻、エントリー時のbid/askまたは実測スプレッド、対象イベント時刻。初回データ取得時、結果を閲覧・採点する前に提供元・価格種別（bid/ask/mid）・取得日時・対象期間・ファイルのハッシュを検証ログのnotesまたは参照するマニフェストへ登録し、そのデータセットを固定する。良い結果の提供元へ差し替えない。必要データが未取得でも基準自体は固定済みであり、架空の値は記入しない。

過去検証の往復コストは1.0pip。フォワードでは仮想終値約定を維持し、観測できた実際の往復スプレッド・手数料等のコストを用いる。取得できなければcost_pips＝UNKNOWNとして結果を保留し、0や1.0で補わない。価格系列に含まれるコストは二重控除せず、コストの算出根拠と含有分をnotesに記録する。実際の本人の約定損益は別記し、仮想ルール成績に置き換えない。

gross_result_r＝(entry−exit)/D、result_r＝gross_result_r−cost_pips/stop_pips。Rの分母Dは当初値に固定する。

## 9. 昇格・判定基準（Promotion Criteria）

過去30件とフォワード20件、計50件終了時に以下をすべて満たすこと：

- 全50件のコスト控除後期待値 >= +0.15R / trade。
- 全50件のProfit Factor >= 1.30。
- 全50件の勝率 >= 45%（コスト控除後result_r > 0を勝ち、建値も分母に含む）。
- フォワード20件の期待値 > 0R。
- フォワード20件のProfit Factor >= 1.00。
- 特定の1時間帯・ニュース・特殊環境への利益集中が80%以上ではないこと。

期待値はresult_rの算術平均。PFは正のresult_r合計 / 負のresult_r合計の絶対値。利益あり・損失0ならPF＝INF、両方0ならUNKNOWNで昇格不可。コスト控除後の平均利益・平均損失・平均RR・最大連敗・再現性・環境別件数もレビューする。新しい連敗の閾値は今回追加しない。

利益集中は、各区分の正のresult_r合計 / 全50件の正のresult_r合計で測定する。全体・過去・フォワードの内訳を併記し、全50件の特定の1時間枠、個別の対象ニュース、または特殊環境gapで80%以上なら全体をAPPROVEDにしない。環境限定の別版・別仮説を検討する。non-eventやnormalの割合が高いだけではこの禁止条件に該当しない。

事前固定の区分：

- session：エントリー時刻のJSTの1時間枠（08:00-08:59等、00時枠を含む）。
- event_tag：構造選定からエントリーまでに対象イベントの「発表10分前〜発表60分後」と重なる場合event、それ以外non-event。禁止区間とは別の分類幅。event_nameには重なった対象イベントすべてを記録し、ニュース別に集計する。
- market_environment：ブレイク直前32本の最新終値−最古終値が正ならup、負ならdown、0ならflat（方向別参考集計）。special_environmentは構造選定〜エントリーの足でabs(open−前足close) >= 10pipsならgap、それ以外normal。特殊環境gapを80%判定に使う。後から発見した特殊環境は補足として記録し、集中を疑う場合は本人レビューまで採用保留とする。結果に合わせて主集計の区分を変更しない。

判定順序：

1. 全昇格基準を満たす → APPROVED候補。自動昇格せず、再現性と証拠の本人レビュー後に状態変更。
2. 全50件期待値 <= 0R、または全50件PF < 1.10 → REJECTED候補。
3. プラスだが昇格基準未達 → TESTING継続。PFがUNKNOWN等で判定不能の場合も保留。

継続時も最初の50件の判定を保持し、その後はフォワードを20件単位で追加して同じ閾値を再評価する。直近20件だけへの都合のよい差し替えは禁止。初回30＋20の基準と追加分・累積を分けて報告する。
