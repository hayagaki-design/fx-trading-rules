## 足番号と逐次判定

終点足を0、次の足を1とする。1本目が確定して終点スイングを確認する。トリガー対象は2〜6本目、6本目が最終判定（ユーザーへの確認済み）。トリガー足kの押し・戻し区間は1〜k−1で、pullback_bars＝k−1（1〜5）。「5本終了まで」は5本の押し・戻しの次に来る6本目の判定までを含む。トリガー足自身をPやSL計算へ含めない。

各kでまず確定済みの押し・戻し区間Pを計算する。LONGは最安値、SHORTは最高値。率が20%未満ならまだトリガー不可。70%超なら即INVALID、同じインパルスを再利用しない。20〜70%ならkのトリガー条件を確認する。未成立ならkを次の押し・戻し区間に取り込み、70%超を再確認する。6本目で成立しなければNO SETUPで終了する。

トリガー足自体のヒゲが70%水準を超えた場合も、「一度でも超えた」を優先してINVALIDとする。ただし有効トリガーのSL用Pは直前までの区間に固定する。この判定は終値が確定してから行い、足内経路を推測しない。

LONG：close > openかつclose > 前足high。SHORT：close < openかつclose < 前足low。両方向ともbody_ratio＝abs(close−open)/(high−low) >= 0.40。high＝lowなら不成立。価格の同値は厳密不等号の成立に含めない。

インパルス幅＝abs(終点価格−始点価格)/0.01。10〜35pips、間隔数2〜8（両端含む）。候補順位は終点の新しさ、次に始点の新しさ。選定した始点・終点・方向をnotesに識別情報として固定し、同じ組み合わせの後続トリガーを再採点しない。

画像不足で適格候補を列挙できない場合はWATCH／必要値UNKNOWNとし、好都合な候補を推定しない。時系列の観測開始・入力画像・判定時刻をnotesへ残す。時間外は新規実注文しない。未エントリー候補は01:00で終了し翌対象時間へ持ち越さない。

## 価格・損益・出口

- LONG：SL＝P−0.01、D＝entry−stop、TP＝entry＋1.5D。
- SHORT：SL＝P＋0.01、D＝stop−entry、TP＝entry−1.5D。
- D > 0、stop_pips＝D/0.01が4〜20（両端含む）。範囲外はNO TRADE。
- 次の足を保有1本目として12本まで判定。TP・SLがともに未到達なら12本目終値で決済。12本目の到達は時間決済より優先。
- 同一足の両到達で順序不明ならSL先行。ギャップでSLを越えて始まれば始値で損切り、TPを越えた有利な始値はTP価格で評価する。下位足による事後的な有利修正は禁止。
- direction_sign＝LONGなら1、SHORTなら−1。gross_result_r＝direction_sign×(exit−entry)/D。
- result_rはコスト控除後：gross_result_r−往復コストpips/stop_pips。HYP-008の過去検証1.0pip仮定は流用しない。観測できた往復スプレッド・手数料等と価格系列（bid/ask/mid）の扱いをnotesに記録し、二重控除しない。不明ならresult_r＝UNKNOWN、gross_result_rはnotesへ別記する。
- MFE/MAEは初期D基準、コスト控除前の非負値。LONGは有利変動＝高値−entry、不利変動＝entry−安値。SHORTは有利変動＝entry−安値、不利変動＝高値−entry。各最大値を0以上としてDで割る。
- MFE/MAEはEntry足を除外する。決済前の完了足の高安と決済足始値・決済価格から計算し、決済後の値を含み得る決済足高安は使わない。5分足による下限値であることをnotesに明記する。画像が足りなければUNKNOWN。

## ステータス・除外・欠損

返答ステータスとCSVのvalidは分ける：

| 返答 | 意味 |
| --- | --- |
| NO SETUP | 適格インパルスなし、期限切れ等 |
| WATCH | 押し・戻しやトリガー待ち、必要情報の確認待ち |
| TRIGGERED | 価格条件の最初のトリガー成立。実注文可否は別途併記 |
| INVALID | 戻し70%超等による構造無効 |

valid＝TRUEは全検証条件適合、FALSEは明確なNO TRADE／INVALID／NO SETUP、PENDINGは条件・決済・コスト等の確認待ち。spread_unknown、event_time_unknown、価格不明はPENDINGの理由を残し、行を削除しない。スプレッド0.5超、SL幅範囲外、イベント禁止区間、時間外はFALSE。0.5ちょうどは許容。禁止区間は発表−10分〜＋15分の両端を含む。

不明値はUNKNOWN、適用外はN/A。UNKNOWNを0、未注文を負け、PENDINGを除外済みと扱わない。可能なら不明行も仮想出口まで追跡する。有効完了30件に数えるのは条件・決済・コストの確認済みTRUEのみ。時系列で前にあるPENDINGは解消または欠損理由を確定するまで初回母集団の決定を保留する。

event_tagはevent / non-event。分類用にインパルス始点〜Entryが対象イベントの発表−10分〜＋60分と重なればevent、それ以外non-eventとする（Entry禁止幅とは別）。対象イベント名・予定／実際の発表時刻・情報源をnotesへ記録する。時刻不明ならUNKNOWN、event_time_unknownで実注文不可。

## リスク数量と日次停止

risk_pctは百分率表記で0.25を格納する（0.0025ではない）。最大許容損失額＝判定時口座残高×risk_pct/100。円口座USDJPYでは、SL価格幅Dと既知の別途コストから1通貨当たり予定損失を計算する。

GMOのユーザー指定操作メモを用いる場合、通貨数＝floor(許容損失額/1通貨当たり予定損失/1000)×1000、GMO注文数量＝通貨数/10000。切り上げ不可。最小単位未満・残高不明・換算不明なら実注文不可。これは0.5%共通上限より厳しい0.25%上限であり、矛盾しない。

日次カウントはJST暦日00:00〜24:00で区切る。日次損益率は、その日開始時の口座残高を分母に固定し、HYP-009のその日に決済した実注文のコスト控除後実現損益の合計を割る。日初残高が不明なら停止判定を推測せず実注文を保留する。

実注文回数は当日新規約定したエントリー数（分割約定は1エントリー）。4回に達したら追加注文しない。3連敗は当日のHYP-009実注文を決済時刻順で数え、建値・勝ちは連敗を切る。累計−1.0%以下・4回・3連敗のいずれかを満たせば翌JST暦日まで新規実注文停止。停止後に既存ポジションが利益で終わっても当日は再開しない。既存ポジションのSL・TPは変更しない。

停止条件は実注文だけに適用し、仮想検証のvalidをFALSEにしない。停止後の適格シグナルも通常どおり仮想Entry・SL・TP・出口を追跡し、notesへdaily_order_stopと根拠を記録する。実注文をしなかったことだけを除外理由にしない。

指定CSVのdemo_ordered / demo_quantityはデモ発注の有無・実際の通貨数専用であり、実注文や推奨数量の欄に読み替えない。実注文の有無・通貨数・約定時刻・決済時刻・実現損益・日初残高・当日回数・連敗数はnotesにreal_ordered等の項目名で記録する。仮想損益と本人の実現損益を混ぜない。
