現時点: OBSERVED 2件、完了した検証0件、APPROVED 0件。観測だけで勝敗・RR・期待値を計算しない。

## 集計単位

仮説ID・条件の版・通貨・時間足・検証方式（実売買／デモ／過去検証）を明示して分ける。1つのエントリーとその部分決済を1取引として合算する。重複事例を別サンプルとして数えない。日時順を保存し、欠損・除外理由も残す。

## 指標

Rはエントリー前に固定した初期予定損失額。建値移動・損切り変更で分母を変えない。初期リスクが不明または0なら損益RはUNKNOWN。損益は同一口座通貨で扱う。

| 指標 | 定義 | 現在 |
| --- | --- | --- |
| 検証回数 | 固定した条件と方式で完了した評価対象取引数N | 0 |
| 勝ち・負け・建値 | コスト控除後の損益が正・負・0の件数 | UNKNOWN |
| 勝率 | 勝ち数 / N。建値も分母に含む | UNKNOWN |
| 平均利益 | 勝ち取引の純利益額の平均。比較用に損益R平均も併記 | UNKNOWN |
| 平均損失 | 負け取引の純損失額の絶対値の平均。Rでも併記 | UNKNOWN |
| 平均RR | 事前の予定利益幅 / 初期損切り幅の平均。分割利確は予定比率で加重 | UNKNOWN |
| 期待値 | 全評価対象の純損益R合計 / N。口座通貨の平均純損益も併記 | UNKNOWN |
| 最大連敗 | 時系列で純損失が連続した最大回数。建値は連敗を切る | UNKNOWN |
| 条件の再現性 | 当時までの情報のみで再判定した条件一致率と不一致理由 | 未検証 |
| 相場環境依存性 | トレンド・レンジ、指標有無、時間帯等に分けた件数・期待値 | 未検証 |

平均RR（計画値）と実現損益R、平均利益R / 平均損失R（ペイオフ比）は別物。期待値は、勝率×平均利益R − 負け率×平均損失Rでも確認できる（建値は0）。勝ち・負けがない区分の平均はUNKNOWNとし、期待値は全取引の直接平均を使う。

純損益は約定に反映されたスプレッド・スリッページを二重控除せず、手数料・スワップ等を含む。過去検証ではコスト仮定を明記する。

UNKNOWNを0で埋めない。欠損があれば指標ごとの有効件数と欠損件数を表示し、完全な成績として扱わない。見送りは取引勝率に混ぜず、事前定義した仮想執行条件の比較群として別集計する。

採用は件数や勝率のみで決めず、再現性・環境別の偏り・コスト・連敗を確認する。HYP-001〜007の採用閾値は未設定。少数事例の好成績だけでは昇格しない。
