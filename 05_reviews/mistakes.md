## HYP-009判定側のミス分類

ミスが確認されたときに上表へ事例ID・発覚日時・判定時の証拠・訂正前後・再発防止を記入する。下表は分類だけであり、実際に発生した件数ではない。HYP-009の正式勝敗や見送り統計へ加算しない。

| code | 具体的なミス | 再確認 |
| --- | --- | --- |
| FORMING_BAR_AS_CLOSED | 形成中5分足を確定トリガー扱い | 足の開始／終了ラベルと確定状態を照合 |
| RETROACTIVE_ENTRY_CHANGE | 遅れて現在価格に仮想Entryを書き換え | トリガー終値と実約定を別記 |
| MOVED_EXIT_LEVEL | TP/SLを事後的にずらした | 初期価格・要求・有効化・決済履歴を保存 |
| REUSED_IMPULSE | 同一始点・終点・方向を再利用 | 元case_idまたはopportunity_idへ紐付け |
| WRONG_TIMEFRAME_HYPOTHESIS | 5分足にHYP-008を適用 | 5分足009、15分足008を確認 |
| PRICE_GUESSED_FROM_IMAGE | 画像の見た目で閾値価格を推測 | 対象足のOHLC表示を取得 |

形成中足をトリガー扱いした過去事例は依頼文に言及があるが、事例ID・日時・証拠は未提供。確認済みミスの実件数に追加しない。[判定運用](../06_statistics/HYP-009-observation-operations.md)に再発防止を記載した。
